? help

A layout is the YAML in the project panel (P): fixtures (kinds of thing), instances (where they are), structures, the show (scenes). The page runs the real hub, so what you see is what a controller gets. Everything stays in this browser.

a new layout

  1. project → new: a starter layout (one panel, two scenes). Or open an example and save as…, or drop a .yaml on the page.
  2. Edit the text, apply (errors show below it), 💾 save. Millimetres, Y up; pos places, rotDeg turns.

scenes

A scene is a pattern + params under a name in show: scenes:; the show cycles them (holdS, fadeS), the crossfader scrubs two by hand ([ ], A auto). Add a line, apply.

fixtures

  • Type one: matrix (cols, rows, pitchMM, wiring), rope (a path, count or pitchMM), tube, dot.
  • From a file: drop it on the page, then builder → new fixture from a file — mesh (CAD with the chips modelled), vxl (baked from Blender / Grasshopper / vox import), gltf; give mm per unit.
  • Place: E builder — click an instance, T move / R rotate, duplicate, ▦ array, ＋ add. Its emitter row is the look, its output row the patch.

patterns

Functions of each LED's real position and normal: ribbonChase planeSweep worldWipe helix lantern swirl drops comet plasma fire strands solid normalRGB spotlight projector. Your own go in src/patterns.mjs (the Node hub, or your own copy of this page).
